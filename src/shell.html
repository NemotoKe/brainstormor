MAKE ROOM FOR IDEAS

気軽に、使いこなそう。

図形を置いたら、そのまま文字を入力。
矢印でつなげば、考えの流れが見えてきます。

選択・移動V
ボードを移動H
四角を置くR
丸を置くO
ひし形を置くD
付箋を置くN
文字を置くT
矢印を引くA
一時的にボードを移動Space + ドラッグ
元に戻す / やり直す⌘ / Ctrl + Z / Shift + Z
複製⌘ / Ctrl + D
ファイルに保存⌘ / Ctrl + S
全体を表示F
選択した要素を削除Delete
右 / 下につながる図形を追加Tab / Shift + Tab
ボード内を検索⌘ / Ctrl + F
次 / 前の検索結果Enter / Shift + Enter
検索を閉じるEscape

図形の文字はダブルクリックで編集。文字を編集していない状態で図形を選び、Tab で右、Shift + Tab で下につながる図形を追加できます。

複数選択すると、右のパネルで位置揃えや等間隔の配置ができます。矢印を選ぶと、ラベル・線の種類・向き・太さを変更できます。

「保存」で .brainstorm ファイルに保存し、「開く」で続きを編集できます。中身は JSON 形式です。

ファイルはあなたの手元に。インターネット接続なしで使えます。

A PLACE TO START

ボードで編集するか、そのままMermaidとして持ち出せます。

「Mermaidを書き出す」は、編集中のボードを変更しません。「ボードで開く」は現在のボードを置き換え、未保存の変更がある場合は確認します。

DIAGRAMS AS TEXT

Mermaidでつなぐ

flowchart / graph のコードを貼り付けると、編集できる図形になります。

対応：基本的なflowchart / graph（四角・丸・ひし形、矢印、ラベル、色）。位置は読み込み時に自動配置します。元の配置を残すには .brainstorm で保存してください。

いまのボードを保存しますか？

ファイルに保存していない変更があります。別のボードを開く前に、続きを残せます。

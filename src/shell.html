MAKE ROOM FOR IDEAS

気軽に、使いこなそう。

図形を置いたら、そのまま文字を入力。
矢印でつなげば、考えの流れが見えてきます。

選択・移動V
ボードを移動H
四角を置くR
丸を置くO
ひし形を置くD
付箋を置くN
文字を置くT
矢印を引くA
一時的にボードを移動Space + ドラッグ
元に戻す / やり直す⌘ / Ctrl + Z / Shift + Z
複製⌘ / Ctrl + D
ファイルに保存⌘ / Ctrl + S
全体を表示F
選択した要素を削除Delete

図形の文字はダブルクリックで編集。矢印は始点から終点へドラッグして引けます。

「保存」で .brainstorm ファイルに保存し、「開く」で続きを編集できます。中身は JSON 形式です。

ファイルはあなたの手元に。インターネット接続なしで使えます。

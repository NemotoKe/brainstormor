# brainstormor

図形に文字を書いて、矢印でつなぐ、小さなブレストツールです。

**`brainstormor.html` をダブルクリックするだけで起動します。** インストール・アカウント・ネット接続・サーバーは不要です。HTML ファイルを持ち運べば、別のパソコンでも開けます。

## 使いかた

1. 四角 `R`・丸 `O`・ひし形 `D` を選び、ボードをクリック。そのまま文字を入力できます。ドラッグすれば、好きなサイズで作れます。
2. 矢印 `A` を選び、図形から図形へドラッグ。つないだ矢印は、図形の移動に追従します。
3. 右上の「保存」または `⌘ / Ctrl + S` で、編集できる `.brainstorm` ファイルとして保存します。

サンプルは [`examples/発想を整理する.brainstorm`](examples/発想を整理する.brainstorm)。「開く」から選ぶか、ボードにドロップしてください。

「テンプレート」では **Mermaidの図の種類** を選んで作成できます。「ブレストボード」タブにはアイデアマップ・判断フロー・ふりかえりもあります。「ボードで開く」は現在のボードを置き換え、未保存の変更がある場合は確認します。

| 操作 | 方法 |
| --- | --- |
| 文字の編集 | 図形・付箋・文字をダブルクリック |
| 付箋 / 文字だけを追加 | `N` / `T` を押してクリック |
| 選択・移動 | `V`、選択した要素をドラッグ |
| 複数選択 | `Shift` を押しながらクリック、または空白から囲むようにドラッグ |
| つながる図形を追加 | 図形を選んで右側の追加ボタン。ボード上では `Tab` で右、`Shift + Tab` で下に追加 |
| ボード内を検索 | `⌘ / Ctrl + F`。検索欄で `Enter` が次、`Shift + Enter` が前、`Escape` で閉じる |
| ボードを移動 | 右クリックしながらドラッグ、または `H`。トラックパッドやホイールでも移動 |
| 横にスクロール | `Shift` を押しながらホイール |
| 拡大・縮小 | 右下の `− / ＋`（約10%ずつ）、または `⌘ / Ctrl` を押しながらホイール |
| 全体を表示 | `F`、または右下の全体表示ボタン |
| 複製 / 削除 | `⌘ / Ctrl + D` / `Delete` |
| 元に戻す / やり直す | `⌘ / Ctrl + Z` / `⌘ / Ctrl + Shift + Z` |

選択した図形の色・文字サイズ・重なり順は、右側のパネルで変更できます。「書き出し」から PNG・SVG 画像として保存することもできます。

- **考えを枝分かれさせる：** 図形を選んで左・上・下・右に追加すると、矢印でつながった図形を作れます。`Tab` の追加は文字の編集中や入力欄では使いません。
- **配置を揃える：** 複数の図形を選ぶと、左右・上下・中心を揃えられます。3個以上では横・縦に等間隔で並べられます。
- **関係をことばで表す：** 矢印を選ぶと、ラベル、実線・破線、片矢印・両矢印・矢印のない線、太さを変更できます。

## 保存について

- **続きの編集や持ち運びには「保存」を使ってください。** `.brainstorm` の中身は JSON です。「開く」またはドラッグ＆ドロップで読み込めます。PNG・SVG は共有用の画像です。
- 「保存」するたびに `.brainstorm` ファイルをダウンロードします。同じ名前で繰り返し保存すると、ブラウザによってファイル名に連番が付くことがあります。
- ブラウザ内にも作業内容を自動保存します。これはファイル保存とは別の復旧用バックアップです。利用したブラウザや HTML の場所に依存し、ブラウザデータの削除などで失われるため、永続的な保管先としては使わないでください。

## 開発する場合

実行用 HTML は同梱済みです。ソースを変更するときは、Node.js で開発用パッケージを入れて再生成してください。公式Mermaid 12.0.0とライセンスをHTMLへ埋め込むため、実行時のネット接続は不要です。HTMLは約5.5MBです。

```sh
npm ci
npm run build
npm test
```

ローカル HTTP で確認したい場合は `npm start`（Python 3 が必要）を実行し、`http://127.0.0.1:4173` を開きます。

## Mermaidとの行き来

**「テンプレート」→「Mermaidの図」** から図の種類を選ぶと、ボードに図を置きます。シーケンス図・フローチャート・クラス図・ER図・状態遷移図・ガントチャート・マインドマップ・円グラフの8種類を用意しています。図はダブルクリックして編集します。

- **かんたん編集（シーケンス図）：** 参加者名、送信元・送信先、メッセージ、送信・応答を選び、上下ボタンで順番を変えられます。名前を変えても接続は保持されます。
- **かんたん編集（フローチャート）：** 工程・条件分岐・開始／終了の図形と、接続先・矢印ラベル・線種を編集できます。接続中の項目を削除するには、先に矢印を変更・削除します。
- **コード編集：** 全8種類で、編集に合わせてプレビューと構文チェックが更新されます。構文エラー中は最後の有効な図を残し、「ボードに反映」は押せません。
- **保存と再開：** 編集内容は「ボードに反映」で確定します。図のMermaidコードは `.brainstorm` ファイルに含まれ、ボードを開き直して再編集できます。ボードからMermaidコードを書き出すこともできます。
- **対応範囲：** 基本的なシーケンス図・フローチャートは構造からコードを自動生成します。`alt`・`loop`・`subgraph`、コメント、変換で失われる装飾などがあるコードは、内容を保つためコード編集で開きます。図の意味や設計の正しさを自動判定する機能ではありません。

図の表示には同梱した公式Mermaidを使います。外部リンク・HTML・外部画像の実行や読み込みは無効です。Mermaidの設定による安全性の変更も無効です。

右上の **Mermaid** では、従来のボードとの変換も利用できます。

- **読み込む**：コードを貼り付けるか `.mmd` / `.mermaid` ファイルを選び、「ボードで開く」を押します。基本的なフローチャートは図形と矢印へ変換します。シーケンス図などはコードを保持した1つのMermaid図としてボードに置き、移動・サイズ変更・ダブルクリックでの編集ができます。通常の「開く」やドロップでも `.mmd` を選べます。
- **書き出す**：Mermaid画面の「書き出す」、または通常の「書き出し」→「Mermaid」。コードをコピーするか `.mmd` ファイルとして保存できます。
- 図の向き（左右・上下）、日本語、矢印ラベル、破線、両矢印、基本的な色に対応。非対応の構文はエラーとして表示し、現在のボードは変更しません。
- Mermaidはつながりを表す形式なので、読み込み時に位置を自動配置します。手作業の配置・サイズを完全に残すには `.brainstorm` 保存を使ってください。画像や図形に接続していない矢印など、変換対象外の要素は書き出す前に画面へ表示します。

ブレストボードの自由な図形への変換は基本的なフローチャートに限ります。[Mermaidの公式構文](https://mermaid.js.org/intro/)と、[読み込み用サンプル](examples/アイデアの判断.mmd)も参照できます。
